# ReviewBoost

Interactive demo of **ReviewBoost**, Google review automation on WhatsApp, by Neovia AI. Demo business: Tandoor Tales Family Restaurant (fictional). All data is seeded; no real messages are sent.

- `/reviewboost`: 3D landing page with a live quick-send demo
- `/reviewboost/dashboard`: owner dashboard prototype (overview, send requests, reviews & AI replies, staff leaderboard, QR standee, settings, plans & WhatsApp booking)

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. Edit contact and UPI details in `config/site.ts`.

Built with Next.js, React, Tailwind CSS and Three.js.
